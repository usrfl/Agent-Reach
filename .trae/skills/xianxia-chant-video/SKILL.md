# 仙气古装念诵视频

用于生成"仙气古装美女双手合掌、念诵南无阿弥陀佛并口型对齐"的竖屏短片，并做成品自检。核心是：把人物造型、光线、镜头、念诵节奏和口型同步写进一条完整导演式提示词，生成后抽帧验证。

## 何时使用

- 用户要"仙气/仙侠/敦煌/古装美女""合掌念诵""阿弥陀佛视频""带有声口型对齐的佛号短片"
- 需要在已有视频基础上换造型、换场景、换节奏

## 生成参数基线

| 项目 | 默认值 | 说明 |
|---|---|---|
| 画幅 | 9:16 | 竖屏短视频；需要横屏时改 16:9 |
| 分辨率 | 720p | 480p 仅用于试稿 |
| 时长 | 10 秒 | 女声慢念"南无阿弥陀佛"两遍约 9-10 秒；一遍用 6-7 秒 |

调用 `GenerateVideo`，一次只调一个，禁止并行；同一轮内若已达调用上限，直接告知用户需下一轮再生成。

## 提示词骨架（按此顺序写）

1. **风格与画幅**：`竖屏仙侠古装唯美短片` / `写实古装电影质感短片`
2. **主角造型**：容貌气质、服制（月白+烟紫渐变广袖仙裙 / 淡青月白交领襦裙）、薄透衣料、披帛、发髻与发饰、妆容；点明"仙气出尘"或"端庄素雅"
3. **动作**：立于何处 → 双手胸前合掌 → 微微躬身 → 缓抬头 → 唇部逐字张合念诵 → 念两遍 → 再合掌；衣袍披帛随风极缓飘动
4. **环境**：云海/白玉台/古寺廊柱/香炉青烟/宫灯，浅景深虚化
5. **光线**：淡金逆光 + 轮廓光/发丝光边；古寺版用黄昏暖金侧光
6. **镜头**：中近景（胸部以上），固定机位极缓慢推近，不晃动
7. **声音**：`女生嗓音安静空灵虔诚，用汉语普通话缓慢清楚地念诵"南无阿弥陀佛、南无阿弥陀佛"，声音与嘴唇动作严格同步对齐`，另配风铃/磬声/木鱼与环境余响
8. **约束**：无字幕、无文字、无标识；单人；无多余动作；`口型必须与念诵音频精确匹配`

口型同步的关键是明确"逐字、缓慢、唇齿与下颌可见运动"，并单独成句强调音画对齐。

## 抽帧自检流程

生成后用以下命令核验，再向用户回报：

```bash
# 1. 规格与音轨
ffprobe -v error -show_entries stream=codec_type,width,height,duration -of default=noprint_wrappers=1 "$VIDEO"

# 2. 音频是否有内容
ffmpeg -i "$VIDEO" -af volumedetect -f null - 2>&1 | grep -E "mean_volume|max_volume"

# 3. 全片接触表（4x5 或 6x4），看构图/人物是否稳定
ffmpeg -y -v error -i "$VIDEO" -vf "fps=2,scale=432:768,tile=4x5" -frames:v 1 /tmp/sheet.jpg

# 4. 面部特写连拍（每 0.25 秒），确认嘴唇张合自然、无面部崩坏
ffmpeg -y -v error -ss 2 -t 6 -i "$VIDEO" -vf "fps=4,crop=W:H:X:Y,tile=6x4" -frames:v 1 /tmp/face_sheet.jpg

# 5. 右下角角标检查（生成器通常带"AI生成"角标）
ffmpeg -y -v error -ss 4 -i "$VIDEO" -vf "crop=300:120:420:1160,scale=600:240" -frames:v 1 /tmp/corner.jpg
```

判定标准：有 AAC 音轨且峰值约 -7dB ~ -5dB（说明有实际人声而非纯静音）；面部连拍中可见连续张口/闭口；无多手、多指、面部畸变、画面闪烁。

## 输出与回报

- 文件放 `/workspace/`，命名如 `<主题>_<风格变体>.mp4`
- 用 `computer://` 链接交付，并列出：规格、造型、动作、声音、以及右下角 AI 角标情况
- 主动给出 2-3 个可继续调整的方向（场景、服制、节奏、画幅）

## 常用变体旋钮

- 服制：唐制齐胸襦裙 / 白衣观音感 / 敦煌飞天（飘带、裸臂钏饰）/ 道袍
- 场景：云海白玉台 / 月夜竹林 / 雪山经幡 / 莲花池 / 古寺大殿
- 氛围：飘落花瓣、飞雪、萤火、莲花浮现、香雾流动
- 节奏：一念 6-7 秒（更慢更庄严）或三念 12-15 秒
